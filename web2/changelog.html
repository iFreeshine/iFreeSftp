Changelog

Version history and feature iterations of iFreeSftp

v0.8.3

Current
  • NewMica background toggle in Settings → Appearance — the Windows 11 Mica material shows through the title bar, window border and container gaps; file areas stay solid for readability
  • FixedImport wizard: wider confirmation table, precise column alignment, subtle header/row separator lines
  • FixedImport button now uses the official Import glyph

v0.8.2

  • NewSession import — one-click migration from WinSCP, FileZilla, PuTTY, OpenSSH config and iFreeSftp archives; passwords and post-login commands are never imported
  • NewConsent-first wizard with a preview table that marks duplicates and missing key files — pick what to import, get a per-item result report
  • FixedUnchecked sources are never probed at all — no file access, no registry reads
  • FixedPuTTY UserName key takes precedence; the same host found in multiple sources is deduplicated within one scan
  • FixedImporting no longer leaves the working set falsely marked dirty after saving

v0.8.1

  • NewUpdate checks — "new version" badge in the title bar, manual check in Settings; publishing a release needs just one Worker variable
  • NewHost passwords encrypted at rest (DPAPI, per-user) — plaintext archives from older versions upgrade automatically
  • ImprovedFingerprint confirmation now covers test-connection too; connections without a fingerprint callback fail closed
  • ImprovedRemote config (announcements, badge, purchase links) applies on restart instead of waiting out the 24h cache
  • ImprovedTransfer-queue pause is now zero-CPU (signal gate); 44-case unit-test suite; icon cache memory capped

v0.8.0

  • NewServer-side command channel: same-host remote→remote cp, instant rm -rf of huge trees, automatic SFTP fallback
  • NewChecksums: SHA-256 / SHA-512 / SM3, server-side first for instant large-file hashing
  • NewBuilt-in AvalonEdit editor: remote text editing, upload on save, conflict detection
  • ImprovedLanguage dictionaries externalized to a locales folder — user-created languages are discovered automatically
  • ImprovedSynced browsing, file comparison, rubber-band selection, cross-pane drag & drop

For earlier releases and all installer downloads, see the releases page.
