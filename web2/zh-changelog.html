iFreeSftp 的版本演进与功能迭代

v0.8.3

当前版本
  • NewMica 半透明背景开关（设置 → 外观）——Windows 11 Mica 材质透过标题栏、窗口边框与容器间隙，文件区保持纯色保证可读性
  • Fixed导入向导：确认页表格加宽、列与表头精确对齐、加入淡淡的表头/行分隔线
  • Fixed导入按钮改用系统官方 Import 语义图标

v0.8.2

  • New会话导入——从 WinSCP、FileZilla、PuTTY、OpenSSH config 与自有存档一键迁移；口令与登录后命令绝不导入
  • New先同意后扫描的导入向导：预览表标注重复项与缺失密钥文件，勾选导入并逐条报告结果
  • Fixed未勾选的来源完全不探测——不碰文件、不读注册表
  • FixedPuTTY 独立 UserName 键优先；同一主机多来源按扫描内判重
  • Fixed导入落盘后不再把工作集误标为脏

v0.8.1

  • New版本探测与更新提醒——标题栏"新版本"徽标、设置页手动检查，发新版只需改一个 Worker 变量
  • New主机密码加密存储（DPAPI 按用户落盘），旧版明文存档自动升级
  • Improved指纹确认覆盖"测试连接"；无指纹回调的连接路径一律拒绝，杜绝绕过校验
  • Improved远程配置（公告、勋章、购买链接）重启即生效，不再等 24h 缓存过期
  • Improved传输队列暂停零 CPU 占用（信号门）；新增 44 用例单测；图标缓存内存封顶

v0.8.0

  • New服务端命令通道：远程→远程同机 cp 直达、海量文件 rm -rf 秒删，自动回退 SFTP 逐条方案
  • New文件校验码：SHA-256 / SHA-512 / SM3（国密），服务端命令优先秒算大文件
  • New内置 AvalonEdit 编辑器：远程文本文件编辑、保存自动回传、冲突检测
  • Improved语言词典外置 locales 目录，用户可自建语言文件并自动被发现
  • Improved同步浏览、文件比对、橡皮筋框选、跨窗格拖拽传输

更早的历史版本与全部安装包下载，请见 发布页。
